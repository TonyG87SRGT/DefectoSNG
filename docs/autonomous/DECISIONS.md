# Decisions

## 2026-11-14

- Production-источник — основной GitHub-репозиторий и отдельный checkout `production/DefectoSNG-main`; экспериментальный agent-lab не используется.
- Первый цикл выбран как исправление надёжности тестового сервера, потому что он не меняет нормативные данные, UI или PWA-кэш.
- Предложенное НК-улучшение с переходами в атласы сохранено в backlog, но отложено до стабильного e2e-контура.
- Неполный Playwright-гейт считается FAIL для публикации независимо от успешных unit-тестов.
- Для текущего изменения production-гейт подтверждён завершённым GitHub Actions run `43606464735` на штатном Node.js 22 и отдельным прямым offline/PWA-сценарием. Локальное зависание общего runner на Node.js 24 не подменяет этот результат и остаётся отдельным техническим долгом.
- Полный production-архив не скачан с VPS: внешняя копия была заблокирована политикой защиты чувствительных данных. Основной snapshot хранится вне web-root с правами 0700/0600.
- Контекстные атласы реализуются через единый `ATLAS_ENTRIES` и фильтрацию по методу; отдельная копия структуры или содержимого атласов не создаётся.
