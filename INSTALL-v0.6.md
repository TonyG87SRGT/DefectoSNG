# Установка DefectoSNG v0.6.0

## Какие файлы изменены

- `sw.js`
- `js/app.js`
- `css/style.css`
- `data/vibration.json`

## Какие файлы добавлены

- `CHANGELOG.md`
- `INSTALL-v0.6.md`

## Обновление через Git

На компьютере или сервере, где находится рабочая копия проекта:

```bash
git pull
```

Если файлы v0.6 сначала копируются вручную в локальный репозиторий:

```bash
git status
git add sw.js js/app.js css/style.css data/vibration.json CHANGELOG.md INSTALL-v0.6.md
git commit -m "v0.6.0: PWA update prompt"
git push origin main
```

На VPS:

```bash
cd /var/www/DefectoSNG
git pull origin main
```

Для статического сайта перезапуск Nginx обычно не требуется.

## Как проверить обновление

1. Откройте действующую установленную PWA до публикации следующей версии.
2. Опубликуйте v0.6.0 на сервере.
3. Вернитесь в PWA или откройте её повторно при наличии интернета.
4. Должно появиться уведомление «Доступна новая версия».
5. Нажмите «Обновить».
6. Приложение перезагрузится один раз и продолжит работу уже с новой версией.

Первый переход с прежней версии может потребовать повторного открытия приложения: старый Service Worker должен сначала обнаружить новый файл `sw.js`. Удалять значок PWA не требуется.

## Откат

Если потребуется откат, верните предыдущий коммит:

```bash
git log --oneline
git revert <хеш_коммита_v0.6>
git push origin main
```

После публикации отката Service Worker снова предложит обновление при обнаружении изменённого `sw.js`.
